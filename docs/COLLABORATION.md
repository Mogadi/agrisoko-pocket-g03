# GitHub collaboration — G03

Repository: https://github.com/Mogadi/agrisoko-pocket-g03

1. Mohammed creates the public repository and invites every member.
2. Paste the markdown in `docs/issues/` into GitHub issues 1–10. Assign the named owner.
3. Each member develops on their named branch. No shared accounts.
4. Every member opens at least one pull request linked to their issue.
5. Every member reviews the previous member’s pull request with a written comment.
6. Merge only after the reviewer is satisfied. Tag `v1.0.0` after the APK exists.

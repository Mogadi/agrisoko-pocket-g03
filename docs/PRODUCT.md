# Product scope — AgriSoko Pocket G03

**Owner:** Mohammed Osama Hasan, Product and GitHub lead

AgriSoko Pocket G03 is a small demonstration product for potato cooperatives, employers and innovation partners in Musanze. A visitor asks who built a feature. The app returns the matching member’s approved profile, confidence, reason and repository evidence.

## Non-goals
- Price forecasting models
- Invented farmer testimonials
- Shared GitHub accounts
- Secrets inside the APK
